# EFFECTS_SPEC

Original specifications for the new effects. These describe **general, public image-processing techniques** and our own tuning. Every slider range and default is **proposed**: tune by eye on the test image set, then update this file with the final values.

Conventions:
- Work in **linear light**, 32-bit float, in the existing scene-referred pipeline.
- Spatial sizes (radii, grain cells) are a **fraction of the image's long edge**, so a 4000px and a 1000px render look the same after downscaling.
- Every effect: strength/amount 0 is an exact **identity**. Deterministic for a given seed. No NaN or out-of-range values on pure black, pure white, or very noisy images.
- CPU reference first, then a WGSL port that matches within the repo's parity tolerance.

---

## 1. Glow

Soft, dreamy highlight glow.

**Technique:** extract highlights above a threshold, blur wide, add back with a screen blend.

| Slider | Range (proposed) | Default | Notes |
|---|---|---|---|
| Strength | 0 to 100 | 0 | Blend amount of the glow layer |
| Size | 0 to 100 | 40 | Blur radius as fraction of long edge (about 0.5% to 6%) |
| Range | 0 to 100 | 50 | Moves the highlight threshold; low values glow only the brightest tones, high values glow most of the image |
| Warmth | -100 to 100 | 0 | Hue shift applied to the glow layer only |

Presets: 6 original styles (names TBD), each a bundle of slider values.

Acceptance: identity at Strength 0; monotonic increase in glow with Strength; scale-independent; no clipping artifacts on white skies.

## 2. Bloom

Light sources expanding into a soft halo.

**Technique:** similar to Glow but driven by a **bright-pass of very high luminance** and a larger, multi-scale (pyramid) blur so small bright points spread wide.

| Slider | Range (proposed) | Default |
|---|---|---|
| Strength | 0 to 100 | 0 |
| Size | 0 to 100 | 50 |
| Range | 0 to 100 | 60 |

Acceptance: a single bright pixel on black produces a smooth, symmetric falloff; identity at 0; scale-independent.

## 3. Halation

Warm fringe around bright edges, as light scatters through film base.

**Technique:** take only the brightest highlights, blur wide, tint red-orange, add back so it fringes bright edges.

| Slider | Range (proposed) | Default |
|---|---|---|
| Strength | 0 to 100 | 0 |
| Threshold | 0 to 100 | 80 |
| Radius | 0 to 100 | 40 |
| Tint | -100 to 100 | 0 (red-orange baseline; shifts toward magenta or yellow) |

Acceptance: only pixels above threshold contribute; identity at 0; no color shift in areas below threshold.

## 4. Film grain (extend existing grain)

Existing sliders (amount, size, roughness, seed) are kept. Add:

- **Luminance response:** amplitude is highest in shadows and midtones and lighter in highlights (proposed curve: amplitude = base * (1 - smoothstep(0.6, 1.0, luminance)) with a small floor).
- **Style Strength** (0 to 100, default 100): scales the color look of a chosen look/style separately from grain. At 0, grain only; at 100, full look.
- **Monochrome vs. chroma grain** toggle (proposed).

Acceptance: deterministic per seed; identity at amount 0; changing size does not change average brightness.

## 5. Original film looks

12 original looks generated by **our own code**: tone curve + per-channel curves + small color-matrix + optional split-toning. No lookup of any commercial film's data, no film-stock or brand names.

Working names: Ember, Harbor, Dune, Fjord, Marigold, Slate, Orchard, Tidepool, Paper Moon, Cinder, Meadow, Dusk.

Each look defines: black lift, highlight roll-off (shoulder), midtone contrast, saturation bias, shadow tint, highlight tint, and optional default grain/halation values.

Looks system: apply any look as one undoable step with a **strength slider** (0 to 100); user can save their own looks (name + parameters); looks are stored as parameter sets, not baked LUT data.

Acceptance: strength 0 is identity; look application is one undo step; save/apply round-trips exactly.

## 6. Vintage texture (light leaks and dust)

- **Light leaks:** soft colored gradients entering from frame edges, seeded procedural shapes (large Gaussian blobs and streaks), screen or add blended.
- **Dust and scratches:** seeded procedural specks and thin lines, small count at default.

| Slider | Range (proposed) | Default |
|---|---|---|
| Light Leaks | 0 to 100 | 0 |
| Dust | 0 to 100 | 0 |
| Seed | integer | 1 |

Command: **Randomize** changes the seed. Works independently of any look.

Acceptance: same seed gives identical output; different seeds differ; amounts 0 give identity; scale-independent.

## 7. Lens blur

Simulated shallow depth of field.

| Control | Range (proposed) |
|---|---|
| Focus shape | linear band or ellipse |
| Position, size, rotation | interactive on canvas |
| Blur Strength | 0 to 100 |
| Transition | 0 to 100 (width of blend between sharp and blurred) |
| Bokeh shape | circle or hexagon |
| Vignette Strength | 0 to 100 |

**Technique:** disc-kernel (or approximated) blur whose radius is driven by distance from the focus shape; highlights above a threshold can be boosted slightly to produce bokeh.

Acceptance: inside the focus shape stays sharp; transition is symmetric; identity at Strength 0; scale-independent.

## 8. Tone tools (working names)

Built on the existing local-Laplacian tone code. Each has 4 preset styles.

| Tool | Sliders |
|---|---|
| **Punch** (dramatic tone) | Strength, Saturation |
| **Expanse** (HDR-style detail) | Strength, Brightness, Saturation |
| **Tone Zones** (tonal contrast) | High, Mid, Low contrast; Protect Shadows; Protect Highlights |

Acceptance: identity at 0; no halos on a hard-edge test image; no hue shifts in neutrals.

---

## Notes on originality

All techniques above (threshold-and-blur glow, multi-scale bloom, tinted highlight scatter, luminance-dependent grain, procedural leaks, disc-kernel blur, local-Laplacian tone mapping) are standard, published image-processing ideas. Tuning values come from our own test images and visual judgment. Do not use any value, shader, asset or look that originates from decompiled or extracted proprietary software.
